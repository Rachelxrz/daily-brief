# 备忘录：1987 型崩盘 vs 六因子宏观闸门

> **背景**：2026-08-04 CNBC 报道 Michael Burry 警告「near a major top, possible a 1987-type fall」，仍持有 SOXX / MU / NVDA / CAT / PLTR / TSLA / AMAT 空头（除 NVDA 外均盈利）。
> **触发疑问**：我的六因子宏观闸门（`macro_gate.py`）此刻**没有任何红灯**，那 Burry 的预测是从哪来的？两者矛盾吗？
> **结论**：不矛盾。两者是**正交**的——闸门测的是「衰退/信用体制」，Burry 押的是「健康经济里的仓位机制闪崩」。闸门在设计上就不为捕捉 1987 型事件而存在。
>
> 存档日期：2026-08-07

---

## 1. 两套逻辑的本质区别

### 我的六因子闸门在监测什么（`macro_gate.py`）

| 因子 | 触发条件 | 性质 |
|---|---|---|
| 波动 VIX | > 28 | 已实现/恐慌波动 |
| 收益率曲线 10Y-3M | 倒挂 < 0 | 衰退领先 |
| 信用 Baa-10Y | z > 1 | 信用压力 |
| 宏观·Sahm 衰退 | ≥ 0.5 | 劳动市场恶化 |
| 宏观·CFNAI 增长 | < -0.7 | 增长动能转负 |
| 趋势 QQQ vs 200 日线 | 破线且斜率向下 | 中期趋势 |

**本质**：这六条都是「**衰退 / 信用体制**」探测器——它们亮红的前提是宏观基本面正在恶化。
**闸门规则**：票数 ≥ 2 **且连续 ≥ 10 个交易日**（约两周）→ 翻 SELL/清仓；否则按 20% 目标波动率决定仓位。仅作用于 QQQ/指数 ETF。

### Burry 的预测走的是完全不同的三条

1. **估值 / 融资结构**：AI 基建需求靠「可能不可持续的融资安排」（循环/供应商融资）撑起——质疑需求的真实性，**不是宏观读数**。
2. **反身性 / 仓位机制**：市场在波动下降中上涨 → 逼 vol-targeting 基金加杠杆 → 带动动量策略跟进 → 自我强化的脆弱循环。**低波动本身成了脆弱性的来源**——这是市场微观结构/拥挤仓位论点。
3. **1987 类比**：把今天的 vol-targeting 基金类比成 1987 年的 **portfolio insurance（组合保险）**——机械抛售级联。

> **一句话**：六因子是「衰退/信用体制」闸门；Burry 押的是「健康经济里的仓位驱动式闪崩」。**他对不对，和我的灯亮不亮没有因果关系。**

## 2. 为什么闸门「本就抓不到」1987 型事件

1. **1987 不是衰退**：当年经济健康、无信用危机、无曲线倒挂、企业盈利没塌——**当年这六个灯也全是绿的**。
2. **VIX、破 200 日线是反应型指标**：1987-type 事件里它们和崩盘**同日或滞后**才亮，事前无预警价值。
3. **10 天持续性闸门是双刃**（见 `PERSIST = 10`）：
   - 设计目的是**防抽风（whipsaw）**——只有「≥2 票」状态**连续 10 个交易日**才动手；中间任何一天票数掉回 <2，计数器归零重数。
   - 对**渐进式衰退熊市**（利差慢慢走阔、失业慢慢上升）是优点，换来回测的平滑（`MaxDD -26.5% / Sharpe 0.81`）。
   - 对**单日/几日的级联式闪崩是天生盲区**：等它连够 10 天，行情早已砸到底，闸门会「跟着往下坐约两周」才清仓。

## 3. 1987 崩盘：程度与恢复时间

### 崩的程度

| 口径 | 幅度 |
|---|---|
| 单日（1987/10/19 道指，Black Monday） | **−22.6%**（−508 点，2246→1739），至今仍是道指史上最大单日跌幅 |
| 单日（S&P 500） | 约 **−20.5%** |
| 峰→谷（8/25 高点 2722 → 10/20 低点） | 约 **−34% 至 −36%**，仅约 2 个月 |
| 全球 | 同步崩，香港停市 4 天 |

### 恢复的时间

- **全年 1987 收正**：崩盘前从年初涨了一大截，崩完后道指全年反而**约 +2.3%**。
- **收复 8 月前高**：道指约在 **1989 年中** 创新高——**从峰顶算约 2 年，从 10 月低点算约 15–19 个月**。

### 为什么恢复这么快

1987 后面**没有跟着衰退**：经济继续扩张、盈利没塌、信用没危机（六因子当年也不会亮红）。崩盘纯粹是 portfolio insurance 机械级联；抛压出尽 + 美联储（格林斯潘上任才两个月）迅速注入流动性并兜底 → 估值就地修复。

|---|---|---|
| **1987 黑色星期一** | ❌ 无 | **~2 年**（当年还收正） |

## 5. 对当前组合的意义

Burry 类比 1987 是**双刃**：

- **坏消息**：这种崩盘闸门事前抓不到（全绿），且 10 天确认期里会跟着往下坐。
- **好消息**：正因**不带衰退**，历史上这类崩盘**恢复也最快**（~2 年，当年往往还收正）。对不加杠杆、能扛两年的长期组合，1987 型事件「吓人但不致命」。

**真正会让组合多年翻不了身的是「带衰退的熊市」——而那恰恰是六因子擅长提前预警的。**

### 需要注意的重叠

Burry 空头标的与本组合的直接重叠：
- **NVDA**（核心持仓）
- **MU / AMD / AVGO / PLTR / SMH-相关**（Watchlist 组一）

即：若发生 1987 型闪崩，本组合的半导体/AI 敞口会是重灾区。

## 6. Burry vs 达利欧：同症、不同框架、相反处方

近期（2026-08 前后）达利欧（Ray Dalio）也在喊「泡沫」，但**框架和 Burry 不是一回事**——他们诊断的是同一个病人，用的却是不同的仪器、不同的扳机理论、相反的药方。

### 达利欧最近说了什么
- **《Diary of a CEO》播客（2026-08 广泛报道）**：AI 出现「经典泡沫特征」，「很像 1929、2000 大崩盘前的样子」。核心比喻：*「财富不等于钱——你只能花钱，不能花财富；要花就得先卖掉财富。」* 大家同时套现时，$100 的 AI 股跌向 $25，而借款还得还 → 去杠杆级联。
- **CNBC（2025-10）**：「我的泡沫指标相对偏高」，把当下比作 1929/2000 前的「80%」、甚至「1927–28」。**关键：「泡沫不会自己破，要等货币政策收紧去戳破。」** 因为美联储在强势中还在宽松，他预期**先来一波流动性「融涨」（melt-up）**，再痛苦回调。
- **2026-05**：把 **2026–2028** 定为「特别危险期」，三条威胁叠加：货币状况恶化、全球对美债需求下降、国际冲突升级。反复引用的财政算术：*「政府花 7 万亿、收 5 万亿——超支 40%」*。

### 达利欧用的是什么框架
三套招牌模板同时跑，当前主推前两个：
1. **泡沫指标（6 表）**——估值 vs 传统、不可持续条件、新手买家、看多情绪、杠杆买入、远期建设。当前读数「偏高」、接近 1929/2000。（诊断工具）
2. **大债务周期（末期）**——美国处于约 75 年债务周期的**最后阶段**，美联储在低失业下宽松＝典型晚周期债务货币化。（机制与扳机）
3. **大周期（Big Cycle）**——主权债务/货币失序、内部政治冲突、大国地缘冲突。（宏观背景）

### 分类：达利欧 = 宏观/债务周期&货币；Burry = 市场微观结构/仓位
- 达利欧的**扳机是货币政策收紧 + 债券供需**（财政赤字、外资对美债需求、货币贬值）——**主权层面**，不是市场管道。
- 他**完全没提** vol-targeting、系统化基金、动量反身性、组合保险机制。唯一沾边「仓位」的是杠杆/纸面财富那段——但被框成**债务**去杠杆，不是**波动率驱动**的机械流。
- Burry 则相反：自下而上的**仓位/管道**论点，带一个**近在眼前的机械扳机**（1987 组合保险类比），并**主动做空**。

### 对照表

| | **Burry** | **达利欧** |
|---|---|---|
| 框架 | 市场微观结构 / **仓位反身性** | **长期债务周期 / 主权宏观** + 泡沫指标 |
| 扳机 | vol-target 被迫加杠杆、动量、1987 式机械解杠杆 | **货币政策收紧** + 利率上行 + 债券供给压力 |
| 核心担忧 | 脆弱的自我强化仓位循环 | 政府债务、财政赤字、美债需求、货币贬值 |
| 时间表 | 迫近的机械式断裂 | 还没到；先融涨；2026–2028 窗口；多十年周期 |
| 动作 | **主动空头**（SOXX/MU/NVDA/CAT/PLTR/TSLA/AMAT） | **分散配置；5–15% 黄金；明确拒绝择时** |

### 重叠 vs 分歧
- **重叠（症状）**：都认为美股/AI 是真泡沫、都点名 **AI 基建的循环/不可持续融资**与 IPO 供给潮、都描述**被迫抛售的去杠杆级联**、都借历史崩盘类比（Burry→1987，达利欧→1929/2000）。
- **分歧（扳机与处方）**：**扳机机制**（vol-target 反身性 vs 货币/主权债务）与**应对**（做空 vs 分散+黄金）根本不同。1987 组合保险机制是 Burry 的核心、在达利欧那里**缺席**。

> **对我们系统的映射**：达利欧的「债务周期/货币收紧」扳机，恰恰**部分落在六因子闸门的射程内**（信用 Baa-10Y 走阔、曲线、CFNAI）——所以*达利欧型*的破裂，闸门更可能提前预警；而 *Burry/1987 型*的机械闪崩，才是闸门的盲区，需要下面第 8 节的脆弱性侧栏来盯。

## 7. 即便没预判到——崩的当天能否知道是「什么性质」的崩？能。

预测崩盘几乎不可能；但**崩盘当天读盘面**，通常足以判断它是**机械/仓位型（1987）**还是**基本面/衰退型**——因为两类崩盘在**跨资产联动**上留下不同指纹。这决定了你该「扛」还是「减」。

| 同日盘面信号（tell） | 机械 / 仓位型（1987） | 基本面 / 衰退型 |
|---|---|---|
| **VIX 期限结构** | 骤然倒挂（前月 ≫ 3 月），急性恐慌 | 也倒挂，但伴随信用持续走坏 |
| **长债 TLT** | **不涨甚至跟跌**＝为流动性无差别抛售 | **避险大涨**＝冲着降息/衰退去 |
| **高收益信用 HYG** | 不比其 beta 额外走坏（管道问题非基本面） | **超 beta 超跌**＝违约/基本面担忧 |
| **黄金 GLD** | **跟跌**＝流动性挤兑（1987、2020-3 初期） | 上涨＝有序避险 |
| **防御 vs 周期**（XLP/XLU vs XLK） | 各板块**无差别同跌**＝去杠杆 | 防御明显抗跌、科技独差＝轮动定价经济 |
| **衰退闸门当日票数** | **0 票**（全绿里突然崩）＝正是 1987 特征 | **≥2 票**＝崩在衰退语境里 |

**判读法则一句话**：
> **股、债、金一起跌 + 信用没额外崩 + 宏观全绿 → 机械型（大概率两年内修复，扛得住就别在恐慌里割）。**
> **长债避险涨 + 信用超跌 + 防御跑赢 + 宏观见红 → 衰退型（恢复以年计，需要真减仓）。**

这套判读已落地为代码（第 8 节），崩盘日自动出诊断；平日则显示「若今日真崩，盘面当前偏向哪种」的预演。

## 8. 已实施：`fragility_gate.py`（脆弱性侧栏 + 崩盘诊断）

> 状态：**已实现并接入**（2026-08-07）。与 `macro_gate.py` 六因子闸门**并列、互不混票**；**不发买卖信号**，只量化「干柴」。输出写入 `docs/data.json` 的 `fragility_gate`，网页「结构监控」页紧贴体制闸门下方渲染；随 `macro_gate.yml`（盘中每小时）与 `daily_brief.yml`（盘后）刷新，**排在 `macro_gate.py` 之后**以读取当日衰退闸门票数。不推送微信。

**A) 脆弱性 / 拥挤度评分（0–5，越高越脆）**
1. VIX 绝对低位（< 14）
2. 期限结构极度平静 contango（VIX3M/VIX-1 > 12% 且 VIX < 16）＝vol-target 加杠杆温床
3. 实现波动处近 1 年最低 20% 分位
4. QQQ 高于 200 日线 > 12%（动量拉伸）
5. Burry 做空篮子（NVDA/MU/AVGO/AMD/PLTR/TSLA/CAT/AMAT/SOXX）RSI 中位 > 65（拥挤在正好要出事的票上）

**B) 崩盘性质诊断**：SPY/QQQ 单日 ≤ −3% 触发；读第 7 节六个 tell，给「机械 vs 衰退」打分并出判定 + 恢复预期提示。

> 注：`K=2` 与 `PERSIST=10` 均为 `macro_gate.py` 写死常量。调低可提升闪崩灵敏度，但会牺牲防抽风、增加交易与回撤波动——本次**未改动衰退闸门任何逻辑**，脆弱性侧栏是独立新增模块。
