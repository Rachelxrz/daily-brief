# CLAUDE.md — daily-brief 仓库项目宪法

本文件是 Claude Code 在本仓库工作的最高约束。与任何临时指令冲突时，先提出冲突再执行。

## 项目是什么

三个组件共存于本仓库，一条共用纪律，不新增项目：

1. **analyst-panel（观点层）**：追踪分析师——带时间戳的可证伪论断、环境快照、复盘、人的校准档案。天/周级。
2. **gate 预警系统（机制层）**：追踪金融体系状态——脆弱性存量、冲击、放大、后盾。月/季级。
3. **predict.py（自我校准层）**：Rachel 本人判断的预测日志与合理化检测（--rationalized）。事件驱动。

共用纪律：point-in-time 数据、experiment registry、fidelity 命名、预登记复盘。

**既有功能不得破坏**：每日双语简报管线（本地 Qwen + Claude API → WxPusher/ServerChan 推送）、国会交易信号（House/Senate Stock Watcher）、动态 watchlist（约 26 标的）、Wheel Strategy 期权模块。任何改动跑通简报全流程后才能合并。

## 硬性规则（违反即返工）

### 数据纪律
- **Point-in-time 铁律**：任何回测/历史分析只允许使用 `available_at ≤ 预测时点` 的数据。宏观数据取 ALFRED vintage，禁止用当前修订值填历史。
- **JSONL 只追加**：analysts/reviews/snapshots 不改写历史行；更正用新行 + `supersedes: <id>` 字段。Git 历史即审计轨迹。
- **schema 先行**：改任何 JSONL 字段必须先改 `scripts/validate.py` 并过 CI；故意写坏的记录必须能被拦截。
- **experiment registry 无豁免**：每次尝试的变量/阈值/权重/训练窗口（含失败版本）都写入 registry.jsonl，哈希 + 时间戳。

### 命名诚实性（fidelity）
- 模块命名四级标签：`replication` / `mechanism_approximation` / `proxy` / `project_specific`；面板纯追踪对象用 `claim_only`。
- 仅在真正复现了公开变量与决策规则时才可标 `replication`。当前系统内**没有**任何模块达到该级。
- 机制层模块名单（重命名后）：`dalio_inspired_bubble`、`grantham_two_sigma`、`valuation_state` + `internals_state`、`passive_liquidity_mismatch`、`tail_fragility`、`macro_credit_gate`。禁止使用暗示"本人原模型"的旧名。

### 统计诚实性
- 系统定位是**强先验阈值情景系统**，不是被估计的概率模型。危机样本为个位数：禁止拟合含交互项的分类器并宣称其校准；禁止把任何综合分数称为"崩盘概率"。
- 自建指标必须与外部基准（OFR FSI、term spread + EBP）并排输出；无相对增量的自建模块降级为引用官方指数。
- 能引用官方公开数据的不自建（见修订补编·可行性分层表）。

### 存储治理（与工作计划书第五节一致）
- 文本与代码一律 GitHub；研报/审计 PDF 一律 Drive `Analyst-Archive/`，仓库内禁止出现任何研报 PDF 或其原文段落。
- md 文档主控在 `docs/`，Drive 副本仅归档；改文档只改 GitHub。
- 每份 Drive PDF 必须有 `drive_file_id` 记录指向；不留孤儿文件。
- 年度备份（C15）：每年 1 月打包上年 briefs+data → Drive `backup/`，单向。

### 复盘纪律
- reviews.jsonl 七字段全部必填（outcome/error_type/timing/missed_factors/key_references/my_action/lesson）。
- 权重更新规则固定：framework-miss 满权重、input-miss 半权重、样本 <5 封顶中性先验。不得事后调整评分窗口。
- 采集只记录"新论断或修正"；修正必须含修正前后值。

## 工程约定

- Python 纯 stdlib 优先（与 predict.py 一致）；确需第三方库先在 PR 说明理由。
- 所有 cron 时间用 UTC 注释换算 ET（数据发布日历以美东为准）。
- 输出双语场景沿用现有简报的中英格式。
- 密钥一律走 GitHub Secrets / 环境变量；Drive 凭证为 service account（R2），禁止入库。
- 每个脚本可独立运行：`python scripts/xxx.py --help` 必须可用。

## 边界（不做的事）

- 不做实时行情系统；不做全网研报爬虫；不追求预测市场目标价。
- 不在压力事件中临时修改决策映射规则（修订补编·修订二的预登记原则）。
- 不删除、不改写任何历史简报与 JSONL 行。
