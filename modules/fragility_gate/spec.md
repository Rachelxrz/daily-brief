# 脆弱性/拥挤度侧栏 + 崩盘性质诊断 — 功能规格 (spec.md)

**模块文件**: `fragility_gate.py`
**创建日期**: 2026-08-07
**状态**: 已实现 v1.0（见 status.md）
**背景/分析**: `notes/1987型崩盘_vs_六因子闸门.md`

---

## 模块目标

补上 `macro_gate.py`（六因子衰退闸门）的盲区：**「健康经济里的仓位机制闪崩」**（Burry / 1987-type）。
六因子闸门监测「衰退/信用体制」，只有宏观基本面恶化才亮红；而 1987 型崩盘发生在宏观全绿、由仓位机械级联引爆——闸门在设计上抓不到。本模块与闸门**正交、并列、互不混票**，且**不发出买卖信号**，只回答两个问题：

1. **盘前**：当前市场「干柴」有多少？（脆弱性/拥挤度评分）
2. **崩盘当天**：这是什么性质的崩？（机械/仓位型 vs 基本面/衰退型）

---

## 功能一：脆弱性 / 拥挤度评分（0–5）

每条命中记 1 分，分数越高越脆。**高分 ≠ 卖出信号**——只说明「一旦有火星，火会烧多大」，不预测火星何时来。

| # | 因子 | 命中条件 | 含义 |
|---|------|----------|------|
| 1 | VIX 绝对低位 | VIX < 14 | 波动卖方舒适、复杂性积累 |
| 2 | 期限结构极度平静 | VIX3M/VIX − 1 > 12% 且 VIX < 16 | vol-target 加杠杆温床 |
| 3 | 实现波动极低分位 | QQQ(^NDX) 20日年化实现波动处近 1 年最低 20% 分位 | vol-target 满杠杆 |
| 4 | 动量拉伸 | QQQ 收盘高于 200 日线 > 12% | 趋势过度延伸 |
| 5 | Burry 篮子拥挤 | 做空篮子 RSI(14) 中位 > 65 | 拥挤在正好要出事的票上 |

**评级**：≥4 = 🔴 高度脆弱；2–3 = 🟡 中度；<2 = 🟢 低脆弱。

**Burry 做空篮子**（与本组合重叠敞口）：`NVDA MU AVGO AMD PLTR TSLA CAT AMAT SOXX`。

## 功能二：崩盘性质诊断

**触发**：SPY 或 QQQ(^NDX) 单日 ≤ **−3%** → 正式诊断；平日仅显示「若今日真崩，盘面当前偏向哪种」的预演。

**判读逻辑**：读同日**跨资产联动**的 6 个 tell，各自倾向「机械型(mech)」/「衰退型(reco)」/「中性」，计票后给判定：

| tell | 机械 / 仓位型（1987） | 基本面 / 衰退型 |
|------|----------------------|-----------------|
| VIX 期限结构 | 骤然倒挂（急性恐慌） | 倒挂 + 信用持续走坏 |
| 长债 TLT | 不涨甚至跟跌＝流动性挤兑 | 避险大涨＝冲着降息去 |
| 高收益信用 HYG | 不超其 beta（管道问题） | 超 beta 超跌＝信用走坏 |
| 黄金 GLD | 跟跌＝流动性挤兑 | 上涨＝有序避险 |
| 防御 vs 科技（XLP/XLU−XLK） | 无差别同跌＝去杠杆 | 防御跑赢、科技独差＝轮动 |
| 衰退闸门票数 | 0 票（全绿里崩） | ≥2 票（衰退语境） |

**判读法则**：
- 股债金一起跌 + 信用没额外崩 + 宏观全绿 → **机械型**（约 2 年内修复，扛得住别在恐慌里割）。
- 长债避险涨 + 信用超跌 + 防御跑赢 + 宏观见红 → **衰退型**（恢复以年计，需真减仓）。

**HY beta**：HYG 对 SPY 经验 beta 取 0.35，超额 = 实际 − beta×SPY，负值越大＝信用越坏。

## 输出

- 写入 `docs/data.json` 的 `[today]["fragility_gate"]`：
  - `frag_score / frag_max / frag_color / frag_label / factors[]`
  - `crash_diag`：`triggered / nature / nature_color / nature_note / mech_score / reco_score / headline / tells[]`
- 网页 `docs/index.html` 「结构监控」页 `renderFragilityGate()`，紧贴体制闸门下方，中英双语。
- **不推送微信**（遵循「微信只推新闻」规则）。

---

## 运行时机

- `macro_gate.yml`（美东盘中每小时）与 `daily_brief.yml`（盘后）中，**排在 `macro_gate.py` 之后**运行，以读取当日闸门票数。
- 均 `continue-on-error: true`，单模块失败不影响整体。

---

## 边界与约束

- **不改动**六因子衰退闸门任何逻辑（`K=2`、`PERSIST=10` 不变）。
- **不发买卖信号**，仅量化脆弱性与诊断性质，不构成投资建议。
- 数据缺失（如个别 ticker 拉取失败）时优雅降级：对应因子/tell 记为「—」或省略，不使整块崩溃。
